# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

### Added

- Added invoice template management page under `Settings > Invoice Templates`.
- Added API-backed invoice template list, create, update, and delete actions.
- Added GrapesJS invoice template editor inside a dialog.
- Added `forceUpdate` support in the invoice template editor flow, allowing admins to update a template in place or create a new version.

### Changed

- Replaced the mock invoice template detail page with a dialog-based editor on the index page.
- Removed hardcoded mock invoice template content from the frontend page.
